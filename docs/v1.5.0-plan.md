# v1.5.0 — Personalization plan

**Status:** Approved for implementation · 2026-11-18
**Builds on:** v1.4.1 settings hub
**Scope:** font picker (including bundled OpenDyslexic), spacing presets, highlight colours and underline mode, and saved/synced defaults.

## Goal

A user can choose a reading font, a text-spacing preset, and a highlight colour or underline style. The choices are saved, sync through the Chrome profile, apply to the next toolbar command, and round-trip through the settings file.

**Acceptance:** choosing a font, spacing preset, and highlight style changes the next command; the choices survive a reload and follow the profile; export/import round-trips them; undo, redo, and Reset page still restore the page exactly.

## Decisions

### Bundled OpenDyslexic: accepted

- OpenDyslexic is licensed under **SIL OFL 1.1** with the reserved font name `OpenDyslexic`.
- Bundle the font unmodified, keep the name, and ship `fonts/OFL.txt`. Attribution goes in the README.
- Ship **regular + bold** WOFF2 (Latin subset) only, at about **115 KB + 120 KB ≈ 235 KB**. Italic is synthesized by the browser; all four styles would add about 229 KB more.
- The current v1.4.1 zip is 70,741 bytes; this would grow it to roughly 300 KB. That is acceptable for a Chrome extension and requires no new permission.
- Fallback stack: `'OpenDyslexic', Arial, sans-serif`.

### Saved defaults define the ON state: accepted

- **Font** turns the chosen font on. A second press removes the override and restores the page's own font.
- **Text spacing** applies the chosen preset. A second press removes it.
- **Highlight** applies the chosen colour and style. A second press removes it.
- Changing a default affects the **next** command. It does not retroactively restyle elements already changed.
- Rationale: deterministic, matches today's toggle and `aria-pressed` model, and avoids another toolbar popover.
- Alternative deferred: a toolbar font/colour picker or a cycle through several fonts. That adds toolbar complexity and announcement work, so it is not in v1.5.0.

### Defaults preserve today's behaviour

- Font: **Sans** (Arial).
- Spacing: **Comfortable**, the current 2 px / 4 px look expressed in `em`.
- Highlight: **Auto** with the current yellow.
- Users opt into OpenDyslexic, WCAG spacing, colours, and underline.
- OpenDyslexic is **not** the default for new installs; Sans stays the default and the font is opt-in.

## Storage and schema

### New synced keys

| Key | Values | Default |
|-----|--------|---------|
| `fontFamily` | `sans`, `serif`, `mono`, `opendyslexic` | `sans` |
| `spacingPreset` | `comfortable`, `wcag`, `custom` | `comfortable` |
| `letterSpacing` | number, `em`, 0–0.5 | `0.125` |
| `wordSpacing` | number, `em`, 0–1 | `0.25` |
| `lineHeight` | number, 1–3, or `null` to leave the page | `null` |
| `paragraphSpacing` | number, `em`, 0–4, or `null` | `null` |
| `highlightColor` | `yellow`, `green`, `blue`, `pink`, `orange` | `yellow` |
| `highlightStyle` | `auto`, `background`, `underline` | `auto` |

### Shared module: `content-scripts/modules/style-defaults.js`

DOM-free, imported by `app.js`, `commands.js`, `options.js`, and `settings-io.js`:

- `DEFAULT_TEXT_DEFAULTS`
- `FONT_STACKS`, `FONT_LABELS`
- `HIGHLIGHT_COLORS` (label, hex, RGB)
- `SPACING_PRESETS`
- `normalizeTextDefaults(values)` — validate, clamp, and fill defaults
- `spacingValuesFor(defaults)` — the effective values for the selected preset
- `highlightValuesFor(defaults)` — colour plus the mode to use

### `prefs.js`

- Split `SYNC_KEYS` (everything) from `LEGACY_KEYS` (`darkMode`, `ttsVoice`, `ttsRate`, `ttsPitch`). New keys must not trigger pointless legacy lookups in `storage.local`.
- Keep the existing lazy migration for the four legacy keys only.

### Settings schema 3

- `CONFIG.settingsSchemaVersion = 3`.
- `PREFERENCE_KEYS` in `settings-io.js` includes the new keys so `hasSettings` recognises a file that only carries text defaults.
- Export writes the new keys flat under `preferences`, consistent with the existing shape.
- Schema 2 files import their known keys and leave the current text defaults untouched. Schema 1 files are unchanged.
- Update the hardcoded schema assertions in `check-v140.js` and `check-v141.js` (both currently assert `schema === 2`).

## Toolbar and commands

### Marker attributes

- `CONFIG.fontAttr = 'data-atx-font'`
- `CONFIG.spacingAttr = 'data-atx-spacing'`
- Keep `CONFIG.highlightAttr`; add `underline` alongside `background` and `outline`.

Markers make the pressed state reliable even when the page's own CSS matches the chosen value.

### Font

- `toggleFontStyle` applies `FONT_STACKS[STATE.textDefaults.font]` with `!important` and sets `fontAttr`.
- Second press removes `font-family` and `fontAttr`, revealing the page's font instead of forcing Arial or Georgia.
- `isCommandApplied('fontStyle')` checks `fontAttr`.
- `clearWrapperOverride` removes `font-family` and the marker.
- This is a deliberate behaviour change from the current serif/sans cycle; note it in the README and release notes.

### Spacing

- `spacingValuesFor` returns the letter spacing, word spacing, line height, and paragraph spacing.
- **Comfortable:** `0.125em` letter, `0.25em` word, no line-height or margin. This matches the current look at 16 px.
- **WCAG 1.4.12:** `line-height: 1.5`, `letter-spacing: 0.12em`, `word-spacing: 0.16em`, and `margin-bottom: 2em` on block targets.
- **Custom:** the stored values, clamped.
- Apply inline with `!important`; remove all four properties on the second press.
- Paragraph spacing applies only to block targets. Inline selection targets cannot take a margin; document this.
- `isCommandApplied('spacing')` checks `spacingAttr`.

### Highlight

- **Auto:** background when the chosen colour keeps text contrast at **≥ 4.5:1**; otherwise outline, as today.
- **Background:** same contrast guard; fall back to underline and announce why rather than making text unreadable.
- **Underline:** `text-decoration-line: underline`, `text-decoration-thickness: 2px`, `text-underline-offset: 2px`, no background.
- Underline and outline colours need **≥ 3:1** against the computed page background. If the chosen colour cannot reach it, use `currentColor` for the line rather than an invisible colour.
- Keep `COMMAND_PROPERTIES.highlight` in sync with the new text-decoration properties.
- **Forced-colors:** use the system `Highlight` colour for outline/underline, because authored background colours are suppressed.

### History and reset

- `captureElementState` and `restoreElementState` include the `font` and `spacing` markers.
- `enhanceSelection` counts a marker change as a change.
- `resetPageChanges` already restores snapshots; verify the new markers are removed with them.
- Extend the undo/redo and Reset page checks.

### Toolbar labels

- Font: `Font: OpenDyslexic · Shift: selection`
- Spacing: `Text spacing: WCAG 1.4.12 · Shift: selection`
- Highlight: `Highlight: yellow background` or `Highlight: yellow underline`
- Recompute labels if the defaults change while a toolbar is open.

## Options page

Add a **Text styling** card after Appearance:

- **Font** select: Sans, Serif, Monospace, OpenDyslexic.
- **Spacing preset** select: Comfortable, WCAG 1.4.12, Custom.
- **Custom sliders** shown only for Custom: line height, letter spacing, word spacing, paragraph spacing, each with a live value and unit. Clamp on input, save on change.
- **Highlight colour** select with a visible swatch; the accessible name includes the colour name.
- **Highlight style** select: Auto, Background, Underline.
- **Live preview** paragraph using the current font, spacing, and highlight. Label it as a preview; keep it out of the AX name clutter.
- **Reset text styling** button, matching the reading reset pattern.
- All feedback goes through the existing `#options-status` live region.

On load, `normalizeTextDefaults` runs over `loadSyncedPreferences`. On change, write the affected keys; on failure, roll the control back and announce. `chrome.storage.onChanged` merges external changes and re-renders.

## Font loading

1. Add `fonts/opendyslexic-regular.woff2`, `fonts/opendyslexic-bold.woff2`, and `fonts/OFL.txt`.
2. Add `fonts/*.woff2` to `web_accessible_resources`.
3. Load in content pages with the **FontFace API** in `app.js`:
   ```js
   const face = new FontFace(
       'OpenDyslexic',
       `url(${chrome.runtime.getURL('fonts/opendyslexic-regular.woff2')})`,
       { weight: '400' }
   );
   document.fonts.add(face);
   face.load();
   ```
   Repeat for weight 700. This avoids relative-URL ambiguity in injected CSS.
4. The options page uses the same faces for its preview.
5. Verify `document.fonts.check('16px OpenDyslexic')` on a normal page, a page with a strict CSP (`font-src 'self'`), and `file://`. If CSP blocks the font, the fallback stack must keep working; record the limitation.

## Risks and mitigations

| Risk | Mitigation |
|------|------------|
| Page CSP blocks the font | FontFace plus stack fallback; test strict CSP; never block a command on font load |
| Paragraph margins shift layouts | Apply only to block targets; keep it behind the WCAG preset; undo and Reset page cover it |
| Low-contrast underline/outline | 3:1 guard against the computed background, else `currentColor` |
| Background colour hides text | 4.5:1 guard; fall back to underline and announce |
| Forced-colors suppresses backgrounds | System-colour outline/underline in `forced-colors` |
| Schema bump breaks old tests | Update the schema assertions in the v1.4.0 and v1.4.1 checks |
| Font button no longer cycles serif/sans | Call it out in README, tooltip, and release notes |
| Package size grows | ~235 KB; no new permissions; still well inside store limits |

## Settled questions

All five were resolved on 2026-11-18 in favour of the recommended option. They are recorded here so later changes have to argue against a decision, not re-litigate an open question.

| Question | Decision |
|---|---|
| Does a saved default define the ON state? | Yes. One toggle per property; no toolbar picker or font cycle in v1.5.0. |
| Which font weights ship? | Regular and bold only. Italic is synthesized; all four styles would add about 229 KB. |
| How is custom spacing edited? | Four sliders: line height, letter spacing, word spacing, and paragraph spacing. |
| Which highlight colours? | Yellow, green, blue, pink, and orange, with a contrast guard on each. |
| Is OpenDyslexic the default? | No. Sans stays the default for new installs; OpenDyslexic is opt-in. |
