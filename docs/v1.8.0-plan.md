# v1.8.0 - Reading flow plan

**Status:** Feature-complete and packaged · 2026-11-26 — continuous reading, sentence navigation, auto-scroll, focus-follow, built-in reading presets, caret ruler, and focus dim are implemented and covered by the harness. The manual NVDA pass and release remain.
**Builds on:** v1.7.0
**Scope:** continuous reading, built-in reading presets, caret-following ruler, focus dim strength, and reading shortcuts. A selection keeps its selection-only scope; a collapsed caret continues to the end of the article, and Shift-click or `Alt+Shift+C` continues from a selection. Custom profiles and Apply to selection are deferred. No new permissions, no network requests, no page mutation without a user action.

## Goal

Make Read Aloud a long-form reading tool instead of a selection-only reader. Start at the selection or caret, continue through the article, keep the spoken sentence highlighted and in view, and let the reader pause, move by sentence, or stop from the keyboard. Built-in reading presets make the existing styling and reading aids reusable in one action.

## Decisions (proposed)

### 1. Continuous reading range

- A non-collapsed selection reads the selection only, preserving the v1.7 behaviour. **Shift-click** Read Aloud or **`Alt+Shift+C`** continues from the selection to the end of the article.
- A collapsed caret reads from the caret's paragraph to the end of the article by default.
- Continue to the end of the nearest `article`, `main`, `[role="main"]`, or `body`, in that order. Do not continue into comments, sidebars, or the next article.
- Skip `SKIP_SELECTOR`, hidden nodes, and empty text. Reuse `buildTextMap`, `buildSentenceMap`, and the existing speech chunker.
- Stop at the end with a short status, clear the highlight, and reset the toolbar.

### 2. Sentence navigation

- The session keeps the sentence map and a current sentence index.
- Previous/next stops the current utterance and starts at the target sentence; SpeechSynthesis cannot seek, so restart from the sentence boundary.
- Highlight the target sentence immediately and keep one chunk queued ahead, as the current reader does.

### 3. Auto-scroll

- After highlighting a sentence, scroll only when its rectangle is outside the middle 60% of the viewport.
- Use `scrollIntoView({ block: 'center' })`; use `behavior: 'auto'` under `prefers-reduced-motion`.
- Do not move focus, and do not scroll the page while the user is actively selecting or editing.

### 4. Pause, resume, and stop

- Reuse the existing pause/resume state and announcements.
- Space pauses/resumes only while a reading session is active and the event target is not editable. Prevent the default page scroll in that case only.
- Escape stops reading after the settings dialog and translation bubble have had their turn.

### 5. Reading profiles

- Built-in presets: **Comfortable** (current defaults), **Dyslexia-friendly** (OpenDyslexic, comfortable spacing, no highlight), **Low vision** (sans, WCAG 1.4.12 spacing, underline or contrast-aware highlight), and **Focus** (serif, WCAG spacing, focus mode on).
- A preset sets the saved text defaults and, in the in-page dialog, the reading-aid toggles. It does not restyle the current selection by itself; the next Font, Spacing, or Highlight command uses the preset.
- The options page mirrors the presets for text styling only. Focus mode and the ruler are page aids and are toggled from the page toolbar.
- Custom profiles and **Apply to selection** are deferred; they need a profile store and a set-style command path that avoids toggling the current state.
- Applying a preset announces the preset name.

### 6. Ruler and focus dim

- New `rulerSource` setting: **Pointer and caret** (default), **Pointer**, or **Caret**.
- Caret mode uses the caret's client rectangle on selection change and keyup. Pointer movement switches to the pointer for that interaction.
- New `focusDim` setting, 0-80, default 55, used by the focus-mode overlay shadow.
- Forced-colors ignores the dim and uses system colours; the ruler stays visible.

### 7. Shortcuts

- `Alt+Shift+R`: Read Aloud; a caret continues, a selection stays selection-only.
- `Alt+Shift+C`: continue from here to the end of the article.
- `Alt+Shift+Right`: next sentence.
- `Alt+Shift+Left`: previous sentence.
- Space: pause/resume while reading, outside editable or interactive controls.
- Validate every combination against Chrome and the existing shortcuts. No new toolbar buttons in v1.8; the reading group is already full.

### 8. Voices

- Keep the existing global voice, language selection, rate, and pitch.
- Per-language voice mapping is deferred; the current `preferLanguage` voice matching stays.

## UX

- The Read Aloud button keeps Play/Pause/Resume and the separate Stop button. Its tooltip names the shortcut and the Shift-click continuation; the accessible name stays **Read Aloud**.
- A selection reads the selection and announces "Reading aloud"; a caret or Shift-click/`Alt+Shift+C` announces "Reading from here". "Reading paused", "Reading resumed", "Reading stopped", and "Finished reading" reuse the toast.
- Sentence navigation does not add a live-region message per sentence; the speech itself is the feedback. The toolbar tooltip names the shortcut.
- Settings **Reading** gains: **Reading presets** (four built-in buttons), **Ruler follows** select, and **Focus dim** slider. The options page mirrors the presets for text styling, plus the ruler source and dim.
- Presets do not change the page until the next Font, Spacing, or Highlight command; the Focus preset turns focus mode on in the in-page dialog.

## Architecture

- **`reading.js`**: continuous range resolution, sentence cursor, next/previous, auto-scroll, end detection, focus-mode coordination.
- **`reading-aids.js`**: ruler source and caret tracking, dim variable.
- **`core.js`**: session fields, `CONFIG` IDs, shortcut labels, preset IDs.
- **`style-defaults.js` / `prefs.js`**: built-in preset values, sync keys for ruler source and dim.
- **`reading-profiles.js`**: the four built-in preset definitions.
- **`settings.js` / `options/options.js`**: preset buttons, ruler source, dim slider, sync and announcements.
- **`settings-io.js`**: schema 5, export/import of ruler source and focus dim; older files leave them unchanged.
- **`app.js`**: Space and sentence shortcuts, storage changes, Escape order.
- **`content.css`**: dim variable, caret ruler, reduced motion, forced-colors, 320 px.
- **`manifest.json`**: new commands for sentence navigation; no new permissions.

## Storage and schema

| Key | Values | Default |
|-----|--------|---------|
| `rulerSource` | `both`, `pointer`, `caret` | `both` |
| `focusDim` | 0-80 | 55 |

- Bump `CONFIG.settingsSchemaVersion` to **5**.
- Existing schema 1-4 files import their known keys and leave the ruler source and dim unchanged.
- Reading presets are code constants that write the existing text-default keys; there is no profile store in v1.8.
- No page text, reading position, or speech content is stored.

## Accessibility contract

- Preset buttons are ordinary labelled buttons; applying one announces its name and result.
- Space is intercepted only during an active reading and only outside editable fields; elsewhere the page keeps its normal scrolling.
- Auto-scroll respects reduced motion, never moves focus, and does not fight a user who is scrolling.
- The ruler and focus overlay stay hidden from assistive technology; the caret ruler does not change the selection.
- Forced-colors uses system colours and keeps a visible ruler.
- The full flow is keyboard-only; 200% zoom and 320 px do not clip the preset or reading controls.
- Read Aloud continues to use the page's language, the translated wrapper's language, and a matching voice.

## Errors and edge cases

| Situation | Behaviour |
|---|---|
| Speech synthesis unavailable | Existing "Speech synthesis not supported" toast; no session starts |
| Selection detached by a re-render | Stop reading, clear the highlight, announce that reading stopped |
| Article end reached | "Reading finished"; clear highlight and reset the toolbar |
| Empty article/main range | Fall back to the paragraph; if still empty, ask for a selection |
| OpenDyslexic blocked | Fall back to Arial, as today; the preset still applies the other values |
| Reduced motion | No smooth scroll; no animated highlight changes |
| Space in a text field | Do not intercept; the field keeps the space |
| Shortcut collision | Detect at startup and use the fallback combination; document it |

## Test plan

- **Unit:** continuous range resolution, sentence cursor and next/previous, preset normalization, schema 5 import/export, ruler source, dim clamping.
- **Browser:** five-paragraph continuous read, auto-scroll, pause/resume, next/previous, stop at the end, detached range, preset defaults and Focus mode, Settings/options sync, import/export compatibility, forced-colors, reduced motion, 320 px, no unintended page mutation.
- **NVDA:** start/pause/resume/next/previous/stop announcements, preset apply, ruler source, dim slider, Space handling.
- **Harness:** full suite plus a new reading-flow suite; package verification and NVDA rows.

## Risks and mitigations

| Risk | Mitigation |
|---|---|
| SpeechSynthesis cannot seek | Restart from the sentence boundary; keep the target highlight immediate |
| Auto-scroll disorients | Comfort band, reduced-motion handling, no focus movement |
| Presets confused with page-wide themes | Label them as saved defaults; page-wide application is deferred |
| Schema 5 breaks imports | Keep older keys, leave new keys unchanged, test schema 1-4 |
| Shortcut conflicts | Validate at startup and in the shortcut conflict harness |
| Long articles and memory | Reuse the text map; cap the continuous range at the end of the article, not the whole document |
