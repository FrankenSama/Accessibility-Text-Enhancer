# v1.9.0 - Translation and selection power plan

**Status:** Draft for review · 2026-11-26
**Builds on:** v1.8.0 (reading flow and schema 5)
**Scope:** multi-block translation, target control, selection expansion, and Settings search. No new permissions, no network requests, no result panel.

## Goal

Finish the v1.7 translation story for long selections: translate every block in a multi-paragraph selection, keep the page structure, and make the whole change one undoable action. Add a direct way to change the translation target, and make sentence/paragraph selection and the growing Settings dialog easier to use from the keyboard.

## Decisions (proposed)

### 1. Multi-block translation

- Replace the v1.7 cross-block rejection with a per-block translation.
- Resolve the blocks with `getBlocksForRange`. For each block, clip the selection to that block and prepare its text.
- Translate every block first, then apply the wrappers in one DOM transaction. If any block fails or the user cancels, apply nothing and leave the page unchanged.
- Use one grouped history entry, so Undo/Redo and Reset page restore or reapply the whole group atomically.
- Show polite progress: "Translating paragraph 2 of 4" with Cancel. Keep the existing first-use target bubble.
- Keep the 5,000-character cap for the **whole selection** in v1.9; report the total and suggest a smaller selection. Per-block caps are a follow-up decision.
- Preserve lists, quotes, tables, and inline context per block. A link or emphasis that contains a whole block stays around that block's translation; a link spanning blocks is split per block and documented.
- After applying, select the whole translated group so Read Aloud can read the result across blocks.

### 2. Target control

- Add a **Swap languages** button to the language bubble. It swaps From and To; when From is Auto, it uses the detected source.
- Add a keyboard path to open the bubble for a saved target, so the user can change the target and translate without going to Settings. Proposed: a new **Translation language** command (`Alt+Shift+L`) that opens the bubble in setup mode with the current target and does not translate until the user presses Translate.
- Keep the target select in Settings and the options page. Do not add a second toolbar button; the reading group is already full.
- Re-translate an existing wrapper with the chosen target after a swap; keep the original for Undo.
- Store only the target, as today. The source is session-only.

### 3. Selection expansion

- Add a keyboard path to select the sentence or the paragraph at the caret:
  - `Alt+Shift+Up`: select the paragraph.
  - `Alt+Shift+Down`: select the sentence.
- Announce the new scope ("Paragraph selected", "Sentence selected") and keep the toolbar and selection in sync.
- Verify that Bold, Highlight, Font, Text spacing, and Contrast apply to every block in a selection. Fix any command that only touches the first block.
- Do not change the browser's native double-click or triple-click behaviour.

### 4. Settings search

- Add a search field at the top of the in-page Settings and the options page.
- Filter cards and rows by visible label and help text; show a result count in a polite live region.
- Escape clears the filter and returns to the full list; focus stays in the search field.
- Do not change any saved setting while filtering.

## UX

- A multi-block selection now translates instead of showing "Select text within one paragraph".
- The bubble shows "Translating paragraph 2 of 4" and Cancel while a group is in flight. A failure names the block and leaves the page unchanged.
- The translated group is selected as a whole; pressing Translate/Show original on any selected wrapper restores the selected wrappers and groups the restore in history.
- **Swap languages** sits between the From and To fields. The new **Translation language** shortcut opens the same bubble for a saved target.
- Sentence/paragraph selection uses the existing toolbar and announces the scope.
- Settings gains a search field with a clear button and a result count.

## Architecture

- **`translation-inline.js`**: block collection, per-block preparation, all-or-nothing apply, group records, progress, swap, language command, multi-wrapper selection.
- **`history.js`**: grouped translation entry, group Undo/Redo, group Reset, partial-failure rollback.
- **`commands.js` / `scope.js`**: translate group vs. single wrapper; paragraph/sentence selection commands.
- **`text.js` / `dom.js`**: block clipping, sentence range helpers.
- **`settings.js` / `options/options.js`**: search filter, swap/target copy.
- **`core.js`**: shortcut labels, command IDs, state.
- **`translation.js`**: batch helper or sequential calls with cache reuse; no service API change unless needed.
- **`content.css`**: bubble swap layout, settings search, group selection visuals (none beyond the existing wrapper mark).
- **`app.js`**: new shortcuts, Escape order, selection guard, storage changes.
- **`manifest.json`**: new commands for the language bubble and selection scopes; no new permissions.

## Storage and schema

- No new stored keys for multi-block translation or target swap.
- `translationTarget` remains the only translation preference.
- Schema stays at **5** from v1.8.0 unless selection scopes need a saved preference; they do not.
- Group history is in-memory only; no page text is stored.

## Accessibility contract

- Progress is polite; a group failure is assertive and names the block. Cancel leaves the page unchanged.
- Each wrapper keeps its target `lang` and `dir="auto"`; Read Aloud reads the selected group in the target language.
- The group selection is a normal DOM selection; the toolbar toggle and Undo/Redo describe the group accurately.
- The swap button has a clear name and state; changing a select does not start a translation until Translate is pressed.
- The new shortcuts do not override text editing, browser shortcuts, or the existing reading shortcuts.
- Sentence/paragraph selection announces the scope and does not move focus unexpectedly.
- Settings search is labelled, announces the result count, and is fully keyboard operable.
- Forced-colors and 320 px layouts hold for the bubble, search field, and Settings.

## Errors and edge cases

| Situation | Behaviour |
|---|---|
| One block fails during translation | Apply nothing; announce the block; offer Try again |
| User cancels mid-group | Apply nothing; close the bubble; page unchanged |
| Apply fails midway | Roll back applied wrappers, restore the originals, do not push history |
| Total over 5,000 characters | Bubble reports the total and suggests a smaller selection; no API call |
| Block boundaries in a list/table | Use the block elements; preserve list items and cells; do not merge blocks |
| Link spanning blocks | Split at block boundaries; document the result |
| Selection spans translated and untranslated wrappers | Restore the translated wrappers in the selection; leave the rest unchanged |
| Target swap with Auto source | Use the detected source; if unknown, ask for the source |
| Translation language shortcut on an untranslated selection | Open the bubble with the current target; do not translate until asked |
| Settings search with no matches | Announce "No settings match" and keep the filter |
| Shortcut collision | Detect at startup and use the fallback; document it |

## Test plan

- **Unit:** block collection and clipping, total cap, group history and rollback, swap normalization, selection scope ranges, settings filter matching.
- **Browser:** two- and five-block translations, lists/quotes/tables, links across blocks, cancel mid-group, failure rollback, Undo/Redo/Reset group, multi-wrapper restore, target swap, language shortcut, sentence/paragraph selection, Settings search, forced-colors, 320 px, reduced motion, NVDA.
- **NVDA:** progress and completion, group restore, swap announcement, language shortcut, scope announcements, search result count.
- **Harness:** new translation group suite plus the existing full suite; package verification.

## Risks and mitigations

| Risk | Mitigation |
|---|---|
| Group history complexity | One grouped entry with records; test Undo/Redo/Reset and partial failure |
| Block boundaries in complex layouts | Use the existing block resolver; test lists, quotes, tables, and nested inline markup |
| Long translations and time | Total cap, sequential calls, cache reuse, progress, Cancel |
| Toolbar crowding | No new toolbar buttons; use keyboard commands and the bubble |
| Shortcut conflicts | Startup validation and the shortcut conflict harness |
| Page structure damage | All-or-nothing apply with rollback; preserve block ancestors |

## Open questions

- Is the 5,000-character cap for the whole selection, or per block with a block limit? Proposed: whole selection in v1.9.
- Should Translate on a multi-wrapper selection restore all selected wrappers, or toggle the whole group? Proposed: restore the selected wrappers.
- Should the language bubble shortcut be `Alt+Shift+L`? Check Chrome and the existing combinations.
- Should paragraph/sentence selection be Up/Down, or a scope cycle on one key?
- Should Settings search also cover the options page in v1.9, or ship the in-page dialog first? Proposed: both, because they share labels.

## Deferred

- Per-site translation targets.
- Per-language voice/translation profiles.
- Page-wide or whole-article translation without a selection.
- A side-by-side bilingual view (still out of scope).
- Persistent translations across reloads.
